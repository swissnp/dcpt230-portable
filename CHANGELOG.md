# Changelog

## 0.4.0

- Add 8-bit grayscale, specialized encoding and a uniform-scanline fast path.
- Add opt-in bounded render caching and CUPS/USB status queries.
- Add native, ARMv6 and ARMv7 regression automation.
- Test both ARM builds on a Pi Zero 2 W; verify normal color printing using usblp.
- Prepare independent source distribution and contributor documentation.

## 0.3.0

- Introduce the native Rust filter, ARM builds and physical two-page validation.

## 0.2.0

- Compress repeated pixels and rows in Python while preserving pixels and copies.

## 0.1.0

- Initial Python PJL/PWG implementation and physical color validation.
